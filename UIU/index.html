UIU陆军处

Unusual Incidents Unit Army Division

UIU陆军处是特异事故处的基本战斗单位，拥有大量的美式战斗单位及武器，似乎与美国政府有大量合作关系。他们拥有强大的情报局支持和特制骇客装置，能直接骇入基金会内部的1级到5级机密文件。

该部队拥有被称为"地表最强人类"的渗透者，据称能用肉身抵御子弹并拥有恐怖的奔跑速度，还有异常尖利的爪刀。基金会推测渗透者本身可能就是一个异常。

尽管战斗能力不弱，但他们对异常的了解"就像三维物种想要了解四维物种一样"，只有模糊的观念，这导致了不少行动失败，曾间接导致精英小组覆灭和金鹰小组被困。

战斗风格完全仿制美国海豹突击队，以小组为单位进行快速、精确、高效率的精准打击，但这种战术在基金会设施内几乎无效。他们甚至对基金会拥有核弹一事保持质疑，认为是战术吹嘘。

核心特性

Core Characteristics

高级骇入能力

拥有特制骇客装置，能突破基金会安全系统，访问机密文件

渗透者单位

"地表最强人类"，疑似异常个体，拥有超常生理能力

美式战术

仿制海豹突击队战术，小组为单位进行精确打击

团队依赖

常与UIU特工组协同行动，单兵作战能力较弱

致命缺陷：对异常现象缺乏真正理解，战术思维停留在常规军事层面，面对超常威胁时常判断失误。

UIU特工组

Unusual Incidents Unit Agent Division

UIU特工组是特异事故处单独成立的专业骇入小组，拥有真正的特制骇客装置，被称为"基金会的安全系统杀手"。由UIU组织内部的高级骇入专员和拥有极强骇入能力的人组成。

编制包括2个骇入小组和3个网络破译小组。不仅是骇入能力高超，渗透和隐蔽能力也是UIU中的顶尖水平。

他们常常在任务执行前的4-5个月甚至1年就潜伏进设施，开展大量内部情报窃取。曾有设施内部高级管理人员被检测出是潜伏许久的UIU特工组成员。

明显缺陷：作战能力几乎为零，依赖性强，人员特别少，一旦损失将对UIU造成沉重打击。装备较为落后，多使用上世纪末的美国制式装备。

行动模式

Operational Patterns
  • 长期潜伏 提前4-12个月渗透进入目标设施，建立内部网络
  • 系统渗透 使用特制骇客装置破解基金会安全系统，窃取机密数据
  • 身份伪装 能够伪装成高级管理人员，长期潜伏不被发现
  • 协同作战 与UIU陆军处紧密配合，陆军处负责保护，特工组负责骇入

特异事故处

Unusual Incidents Unit Accident Division

UIU特异事故处是UIU最基本普遍的作战单位，适用范围比陆军处更广，更多出现于大众之中。他们在UIU内部被称为"天平"，平衡了UIU内部装备武力带来的差异。

相比于陆军处，他们似乎更适合在设施内部、未知环境以及异常面前战斗，拥有较强的战场适应能力和单兵作战能力。但部分装备的差异导致行动多以失败告终。

主要装备是美军的退役装备，战术单位也基本是快被淘汰的美军装备。尽管如此，他们仍拥有较强火力，足以在设施外围撕开防线。

可惜的是，UIU高层没有足够的精力和财力来提升特异事故处，导致他们正在淡出大众视野。
