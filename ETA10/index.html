单位简介

Mobile Task Force ETA-10 "See No Evil"

ETA-10 "非礼勿视"是基金会专门针对视觉型异常收容失效组建的特种部队。该单位名称源自儒家经典，强调对危险视觉信息的回避原则。

与常规收容部队不同，ETA-10专注于处理那些通过视觉感知传播的异常效应。这些异常可能包括：直视会导致精神影响的实体、传播认知危害的图像、引发物理变化的视觉现象等。

ETA-10成员经过严格的视觉防护训练和特殊的视觉系统改造，能够在致命视觉环境中执行收容任务。部分成员甚至接受了手术改造，使其能够在闭眼或视觉受限状态下有效作战。

该单位通常部署在发生SCP-███、SCP-096、SCP-173等视觉型异常收容失效的场合，或在预见到此类风险时进行预防性部署。

专用装备

Specialized Equipment

ETA-10配备了专门针对视觉型异常的特制装备：

  • 认知危害过滤护目镜 可自动检测并模糊危险视觉信息，提供多层光学防护
  • 间接观察系统 通过摄像头和屏幕间接观察目标，避免直接视觉接触
  • 频闪抑制设备 可产生特定频率的光脉冲，干扰某些视觉型异常的效应
  • 快速遮蔽系统 可迅速部署视觉屏障（雾、幕布、不透明涂层等）
  • 视觉记忆删除装置 对受影响人员进行可控的记忆删除，消除视觉危害残留
装备使用警告

所有ETA-10装备均需专门培训后方可使用：

  • 不当使用护目镜可能导致防护失效或意外暴露
  • 间接观察系统存在延迟，不适合应对快速移动目标
  • 频闪设备可能引发癫痫患者发作
  • 视觉记忆删除必须由认证人员执行，否则可能导致永久记忆损伤

常见应对异常类型

Common Anomaly Types

ETA-10专门应对以下类型的视觉异常：

直视触发型

需要被看到才会激活的异常（如SCP-096、SCP-173）

图像传播型

通过图像、视频传播的认知危害（如SCP-███）

光效应型

通过特定光线或颜色产生异常效应

视觉实体型

只能在特定视觉条件下被感知的实体

典型案例： ETA-10在Site-19的SCP-173收容失效事件中表现出色，
通过使用交替眨眼战术和团队视觉覆盖协议，
在零伤亡情况下成功重新收容了该异常。
